# SOYLOK Motion Studio

Локальный видеоредактор с графическими эффектами и трекингом лица и рук поверх видео.

## Запуск

Нужен Node.js 18 или новее. Устанавливать зависимости через `npm install` не требуется.

```sh
npm start
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173) в браузере. Другой порт: `PORT=5174 npm start`.
Открывайте редактор через сервер: загрузка моделей и JavaScript-модулей требует HTTP.

## Две версии

Переключатель сверху открывает две независимые версии:

- **gpt-5.6-sol** — архив из коммита `3ba932e`, до последнего пуша `e4a2567`. Оригинальный интерфейс и эффекты сохранены.
- **gpt-6-astra** — текущий редактор. Он открывается по умолчанию с выбранным автомонтажом.

Ссылки: [gpt-5.6-sol](http://127.0.0.1:5173/?version=gpt-5.6-sol) · [gpt-6-astra](http://127.0.0.1:5173/?version=gpt-6-astra). При переключении предыдущая версия выгружается, поэтому её звук и обработка не продолжают работать в фоне.

## Возможности gpt-6-astra

Новые мотивы референса: рисующаяся подпись, плотный поток плюсов вверх с реакцией на басовые атаки, линии с подписями по точкам глаз и кистей, густой дождь из штрихов. Каждый доступен отдельно и включается в автомонтаж. Для произвольного объекта можно задать подпись и фиксированную точку нажатием на кадр.

- Автомонтаж идёт первым и включён по умолчанию. «Новая композиция» заново выбирает сцены, меняет их порядок, длительность, темп и оформление. На коротком клипе используются выбранные мотивы; на длинном появляются повторения с другими схемами.
- 27 отдельных эффектов: оранжевый титр, кресты, шахматный пол, вертикальные штрихи, цветовые блоки, погодная карточка, белые человечки, портретная вставка, контурные рамки, диски, эхо текста, текстовый коллаж, орбиты, горизонтальный сигнал, текстовые ленты, геометрия, разделённый кадр, плавные линии, контактный лист, лучевой знак, штамп, белый контур и колонка титров.
- У каждого из 27 эффектов есть четыре структурные схемы и параметры для вариаций внутри них: 108 схем до изменения масштаба, положения, количества элементов и движения. Шахматный ритм включает пол, плоскости и крупную плитку. Плотность по умолчанию — 65%.
- Библиотека с настоящими превью и фильтром по типу эффекта. Превью обновляются вместе с композицией. «Предыдущая» возвращает прошлый вариант; номер композиции сохраняется в этом браузере.
- «Новая композиция» находится прямо над видео, в левом верхнем углу. Название активной сцены показывается под таймлайном. Кнопка управления не попадает в экспорт.
- Логотип «Дикси» появляется только в последние 3 секунды (для коротких роликов — последние 20%): мигает в разных углах и остаётся справа внизу на финальном кадре. Одинаково работает в предпросмотре и экспорте; в режиме оригинала скрыт.
- В композициях с несколькими окнами видео трекинг учитывает масштаб и обрезку каждого окна.
- Настройка плотности графики, цвета акцента и композиции; сравнение с оригиналом.
- При одинаковом номере композиции и времени рисунок воспроизводится при перемотке и экспорте. Новый вариант меняет графику, сохраняя загруженное видео, введённый текст и настройки трекинга; точки лица и кистей не рандомизируются.
- Распознавание лиц и рук с MediaPipe: рамки, контуры и скелеты рисуются поверх исходника.
- Реакция эффектов на амплитуду, частоты и атаки звука из видео.
- Экспорт всего ролика со звуком, эффектами и трекингом, с сохранением пропорций исходника. Доступны исходный размер и ограничение до 1080p или 720p.

Видео, модели распознавания и обработка остаются на устройстве. Выбранные файлы не загружаются на сторонний сервер. MediaPipe и модели включены в проект в каталогах `vendor/` и `models/`.

## Ограничения

При первом экспорте редактор заранее анализирует движение с частотой 8 кадров/с. Затем записывает ролик в реальном времени: минутный ролик записывается примерно минуту после анализа. Результаты анализа используются повторно, пока не выбран другой файл. Оставляйте вкладку активной до завершения. Целевая частота записи — 30 кадров/с; браузер выбирает доступный кодировщик MP4 или WebM. Распознавание вынесено в Web Worker и не блокирует отрисовку. Итоговая плавность зависит от производительности устройства.

Поддержка входных видео и кодеков зависит от браузера. Для работы рекомендуется актуальный Chrome или Edge. Трекинг может терять лица и руки при перекрытиях, смазанных кадрах, слабом освещении или слишком мелком объекте; в таких случаях счётчик обнаружений показывает фактический результат.

Проверка синтаксиса JavaScript-модулей:

```sh
npm run check
```

Композиции вдохновлены графикой референса. Погодная карточка использует окна видео без вырезания человека; контактный лист показывает разные кропы текущего кадра. Архив gpt-5.6-sol сохраняет свои исторические зависимости и ограничения.
